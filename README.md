# Old McArdle’s Farm — Preview

This is a static, demonstration-only preview of the public farm website and a sample farm dashboard.

## Important
- This preview is not connected to Supabase or any live farm systems.
- Demo inventory and any requests are stored only in the visitor’s own browser.
- No real customer information, passwords, API keys, or payment processing belong in this preview.
- The dashboard is a visual prototype, not a secure administrative system.

## Publish with GitHub Pages
Upload `index.html`, `.nojekyll`, and this README to the root of a dedicated public repository. Then open Settings → Pages and select Deploy from a branch, branch `main`, folder `/(root)`.
